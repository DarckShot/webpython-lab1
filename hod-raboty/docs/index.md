# Как меняется время обработки данных

На учебном наборе сравниваем длительность базового и оптимизированного
вариантов алгоритма при трёх размерах входа. Длительности в исходном CSV
заданы вручную для демонстрации конвейера. По этому набору нельзя сделать
вывод о производительности реального алгоритма.

[Открыть график, таблицу и данные](results/index.md){ .lab-link }

## Метод расчёта

Для каждого размера берём медиану времени по повторам отдельно для каждого
варианта. Ускорение вычисляем делением медианы базового варианта на медиану
оптимизированного. Значение больше единицы соответствует меньшей длительности
оптимизированного варианта в исходной таблице.
